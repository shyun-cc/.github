# 嵩湖雲 · SHYUN

[简体中文](./README.md) | [English](./README.en.md) | 繁體中文

**標準化產品，兼顧行業深度。** 嵩湖雲為製造業、餐飲零售、社群物業與租賃服務等行業提供 SaaS 平臺和開源業務基礎。產品開箱即用、配置靈活，幫助中小企業實現業務數位化。

官網 [shyun.cc](https://www.shyun.cc) · 聯絡 [ilovintit@gmail.com](mailto:ilovintit@gmail.com)

## 關於嵩湖雲

嵩湖雲源於多年的企業導入軟體的經驗。我們將多個專案中反覆驗證的模組沉澱為標準化產品與多端開源基礎設施。

- **開箱即用。** 支援在真實生產場景中快速落地。
- **靈活配置。** 在通用底座上按行業業務流程擴充套件。
- **成熟架構。** 前端、後端及多端元件均已在生產環境中使用。
- **多端支援。** 覆蓋桌面 Web、移動 Web（H5）、微信小程式和原生 Android。
