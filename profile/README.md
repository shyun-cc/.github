## 🤝 理念与参与

- **真实场景驱动**：所有项目均提炼自真实生产业务，拒绝过度抽象与玩具代码。
- **Agent-Native 工程规范**：清晰的模块化边界、严格只读静态门禁与可复现的自动化 CI，让人类开发者与 AI Agent 高效协同。
- 欢迎通过各仓库的 **Issues** 与 **Pull Requests** 交流反馈、共同完善！
